# Writing style

Rules: `anti-ai-writing-style.md` at the SDK root (the single source). Read it once per session when writing.

## Steps
1. Draft for the reader's next action: lead with the claim, then the evidence.
2. Apply the checklist in `anti-ai-writing-style.md` line by line, cutting every pattern it lists.
3. Read it aloud mentally. If a sentence would not be said by a senior colleague in a meeting, rewrite it.
4. Keep the domain terms the protocol defines (§N, tags, statuses) exactly as written.
